# Crna Gora — путеводитель для двоих

Интерактивная страничка с 50 местами Черногории. Голосование на двоих, заметки, фильтры, карты, синхронизация между устройствами через jsonbin.io.

---

## Что внутри пакета

- **`index.html`** — вся страница, один файл (~125 КБ). Шрифты, стили, картинки, логика — всё внутри.
- **`.nojekyll`** — пустой технический файл, говорит GitHub Pages не пытаться обрабатывать страницу как блог.

Этого достаточно для публикации.

---

## Как залить на GitHub Pages (5 минут, без терминала)

### 1. Создать репозиторий

1. Зайти на [github.com](https://github.com), нажать `+` сверху справа → **New repository**.
2. Имя репозитория — любое, например `montenegro`. Сделать **Public** (для Pages на бесплатном аккаунте нужно public).
3. Поставить галку **Add a README file**.
4. Нажать **Create repository**.

### 2. Загрузить файлы

1. В созданном репозитории нажать **Add file → Upload files**.
2. Перетащить туда `index.html` и `.nojekyll`.
3. Снизу — **Commit changes**.

### 3. Включить GitHub Pages

1. В репозитории открыть вкладку **Settings**.
2. В левом меню — **Pages**.
3. В блоке **Build and deployment** выбрать:
   - Source: **Deploy from a branch**
   - Branch: **main** (или **master**, если так называется), папка **/(root)**.
4. **Save**.

Через ~1–2 минуты страница станет доступна по адресу вида:

```
https://<имя_аккаунта>.github.io/<имя_репозитория>/
```

GitHub покажет ссылку прямо в разделе Pages.

### 4. (Опционально) Свой короткий адрес

Если есть свой домен — в том же Pages указать **Custom domain**, добавить CNAME-запись у регистратора. Если нет — ссылка `имя.github.io/...` тоже работает.

## Как настроить синхронизацию между двумя устройствами

На странице используется бесплатный сервис [jsonbin.io](https://jsonbin.io) как общая «корзина» для голосов и заметок. Один раз настроили — дальше всё само.

### Один раз (любой из партнёров):

1. Зайти на [jsonbin.io](https://jsonbin.io), зарегистрироваться (бесплатно, e-mail + пароль).
2. На сайте jsonbin открыть раздел **API Keys** в левом меню.
3. Скопировать свой **X-Master-Key** — длинная строка, начинается с `$2a$10$...`.
4. Открыть свою опубликованную страницу.
5. В правом нижнем углу — индикатор синхронизации, кликнуть на него (или нажать «⚙ Настройки» в тулбаре).
6. Вставить Master Key и нажать **«Создать общее хранилище»**.
7. После создания появится **ссылка для партнёра**. Скопировать и отправить (WhatsApp, Telegram, любой канал — желательно личный).

### Партнёр:

1. Открывает присланную ссылку (один раз).
2. Страница автоматически подхватывает то же самое хранилище.
3. Дальше можно открывать просто по основному адресу `имя.github.io/...` — настройки уже сохранены в браузере.

### Дальше:

- Каждый голосует со своего устройства.
- Изменения подтягиваются автоматически каждые ~25 секунд (если страница открыта).
- Можно нажать «Обновить сейчас» в настройках, чтобы подтянуть прямо сейчас.

## Важные замечания

- **Ссылка для партнёра содержит Master Key** — это позволяет писать в хранилище. Отправлять её надо приватно (как пароль). Никогда не публиковать в открытых местах.
- **Master Key даёт доступ ко всем вашим bin'ам на jsonbin.** Если параноидально — заведите для этой страницы отдельный аккаунт на jsonbin (5 минут).
- **Бесплатный лимит jsonbin** — 10 000 запросов в месяц. Для двоих с автообновлением раз в 25 секунд это около 7 часов непрерывного использования в день. С запасом достаточно.
- **Если синхронизация отвалится** — данные останутся локально в браузере. Кнопка в индикаторе («Обновить сейчас») попробует переподключиться. В крайнем случае — отключить синхронизацию и работать локально.
- **Браузерное хранилище привязано к домену.** Если позже поменяете адрес страницы (другой репозиторий, свой домен) — настройки придётся ввести заново.

## Что внутри страницы (краткое описание для контекста)

- **50 мест** Черногории, ранжированных по 4 уровням (Жемчужины · Очень стоит · С оговорками · Углубление).
- У каждого места: описание, плюсы, минусы, опасности, изюминки.
- **Голосование** двух человек («Он хочет» / «Она хочет»). Когда оба нажали — карточка подсвечивается золотом.
- **Заметки** к каждому месту, сохраняются между сессиями.
- **Фильтры** по уровню и по голосам.
- **Галерея** с атмосферными иллюстрациями + кнопки на Google Images / Yandex Images для реальных фото.
- **Карта** — каждое место открывается в Google Maps в новой вкладке.

## Технически

- Чистый HTML/CSS/JS, без сборки и зависимостей.
- Все стили и логика — в одном `index.html`.
- Шрифты подгружаются с Google Fonts (`Fraunces`, `EB Garamond`, `Big Shoulders Display`).
- Иконки и иллюстрации — встроенные SVG, никаких внешних картинок (работает за корпоративными прокси и блокировщиками).
- Хранилище: jsonbin.io REST API + localStorage как кэш.
- Никакой аналитики, никаких трекеров.
